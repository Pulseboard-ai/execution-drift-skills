# agent-done-chain

Verifies whether an AI agent's "task complete" claim is actually true —
eight evidence-based checks, run against the agent's own transcript,
before you trust it.

Part of the [execution-drift-skills](https://github.com/Pulseboard-ai/execution-drift-skills) pack.

See SKILL.md for the full method. See samples/ for three planted-failure
transcripts and an answer key — run the skill against them and score it
before pointing it at anything real.

MIT license. No network calls. No telemetry. Free permanently.
