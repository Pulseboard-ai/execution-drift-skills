# Memo lint (leader mode)

Check an incoming escalation before deciding. Report pass/fail per line, then one sentence: decide now, or send back with which items.

- [ ] Blocker stated in one sentence with evidence (ticket/PR/date)
- [ ] Blocker type named
- [ ] 2–3 options that differ in outcome, not tone
- [ ] Each option has pros, cons, and a reversibility tag
- [ ] Data or estimate behind each option, labeled as which
- [ ] Cost of delay per week, with unit
- [ ] Affected stakeholders listed and pre-wired (says who's seen it)
- [ ] Recommendation present, or an explicit "balanced — your call" with why
- [ ] The ask: what decision, from whom
- [ ] Deadline for the decision
- [ ] Default if no decision by the deadline
- [ ] Under one page

Send-back rule: missing ask, deadline, or default → send back. Missing anything else → decide, note the gap.
